WHAT IT DOES
============

System Call Interface:
  - Provides direct CPU/memory access from Python
  - Uses ctypes/cffi to call C functions
  - Enables memory mapping, raw syscalls, memory read/write
  
Binary Compatibility Layer:
  - Loads and executes native Linux ELF binaries
  - Intercepts syscalls and translates to microkernel API
  - Installs .deb packages
  - Works like Wine (Windows apps on Linux) or WSL (Linux on Windows)
  
VirtualBox Persistence:
  - Reads/writes VirtualBox .vdi disk images
  - Mounts as /mnt/persistent
  - Ensures data survives VM reboots
  - Auto-mounts on boot via /etc/fstab

ARCHITECTURE
============

Boot Flow:
  BIOS → ISOLINUX → Linux Kernel → Init → /etc/init.d/S99minikernel
  → python3 -m minikernel.boot → MicroKernel services → Interface

Storage:
  / (RAM from ISO - read-only OS)
  /mnt/persistent (VDI - persistent user data)
  
Binary Execution:
  Download .deb → Install via BCL → Binary executes with syscall
  interception → Syscalls translated to microkernel API → 
  syscall_bridge to CPU → Data persists to VDI
