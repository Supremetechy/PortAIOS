QUICK START
===========

1. Build the bootable ISO:
   
   cd minikernel/buildroot
   ./build.sh
   
   Time: 1-2 hours (first build)
   Output: output/minikernel.iso

2. Create VirtualBox VM:
   
   ./create_vm.sh
   
   This automatically:
   - Creates VM with 2GB RAM, 2 CPUs
   - Attaches bootable ISO
   - Attaches 8GB persistent disk
   - Starts the VM

3. First boot setup:
   
   Login: root
   Password: minikernel
   
   Format persistent disk (first boot only):
   # mkfs.ext4 /dev/sda1
   # reboot

4. Use MiniKernel:
   
   # minikernel          (voice interface)
   # minikernel-cli      (command-line interface)

WHAT YOU GET
============

✓ Bootable ISO (~400 MB)
✓ Persistent VirtualBox disk (8 GB)
✓ System call interface (C bridge for CPU/memory access)
✓ Binary compatibility layer (run native Linux executables)
✓ VirtualBox .vdi disk support
✓ Voice-controlled AI interface
✓ Natural language command processing

ARCHITECTURE
============

Three Core Components:

1. System Call Interface (minikernel/core/native/syscall_bridge.c)
   - Direct CPU/memory access via ctypes
   - mmap(), syscall(), memory read/write
   - Zero-copy performance

2. Binary Compatibility Layer (minikernel/core/elf_loader.py)
   - Load and execute native ELF binaries
   - Intercept syscalls → translate to microkernel API
   - Install .deb packages
   - Like Wine/WSL but for MiniKernel

3. VirtualBox Persistence (minikernel/core/disk_image.py)
   - Read/write .vdi disk images
   - Mount as /mnt/persistent
   - Data survives reboots

SYSTEM REQUIREMENTS
===================

Build Host:
- Linux (Ubuntu/Debian/Fedora/RHEL)
- 10 GB free disk space
- 4 GB RAM (8 GB recommended)
- build-essential, libncurses-dev, rsync, wget

VirtualBox VM:
- VirtualBox 6.0+ installed
- 512 MB RAM minimum (2 GB recommended)
- 8 GB disk space

TROUBLESHOOTING
===============

Build fails?
→ Install: sudo apt-get install build-essential libncurses-dev rsync

VM won't boot?
→ Enable VT-x/AMD-V in BIOS
→ Check boot order (CD/DVD first)

Persistent disk not working?
→ Format on first boot: mkfs.ext4 /dev/sda1
→ Reboot

Voice not working?
→ Enable audio in VirtualBox settings
→ Check ALSA: aplay -l
