# Voice & Gesture UI Control - Quick Start Guide

## 🎤 Voice Commands

### Wake the System
1. Say **"Hey AIOS"** or click the microphone button
2. Wait for "Listening..." indicator

### Basic Commands

#### Buttons
```
"Click demo"
"Press greet"
"Activate theme selector"
"Boot minikernel"
```

#### Dropdowns
```
"Set palette to cyan"
"Change activity to thinking"
"Matrix colors"
```

#### Sliders
```
"Set smile to 0.8"
"Increase surprise"
"Maximum detail"
```

#### Inputs
```
"Focus speech input"
"Open command input"
```

## 👋 Gesture Commands

### Setup
1. Click the gesture help button (👆)
2. Allow camera access
3. Ensure good lighting

### Gestures
- **Point** 👉 → Highlight element
- **Thumbs Up** 👍 → Click/activate
- **OK** 👌 → Confirm/focus
- **Swipe Right** ➡️ → Increase slider
- **Swipe Left** ⬅️ → Decrease slider

## 📋 Quick Test
