## 🚀 Quick Start (Complete System)

### 1. Basic Setup
```javascript
// Open avatar-integration.html
// Say "Hey AIOS" to activate
```

### 2. Try Voice Command
```javascript
// Say: "demo mode"
// Say: "blue theme"
// Say: "happy face"
```

### 3. Try Gesture
```javascript
// Show peace sign ✌️ for screenshot
// Show 3 fingers for counting
// Wave → Fist → Peace for secret handshake
```

### 4. Create Profile
```javascript
window.AIOS.userProfiles.createProfile({
    username: 'yourname',
    customizations: { theme: 'synthwave' }
});
```

### 5. Setup Integration
```javascript
window.AIOS.externalIntegrations.registerIntegration({
    name: 'Slack',
    type: 'webhook',
    config: { url: 'YOUR_WEBHOOK', trigger: 'voice_command' }
});
```

### 6. Apply Theme
```javascript
window.AIOS.themeSystem.applyTheme('neon');
```
