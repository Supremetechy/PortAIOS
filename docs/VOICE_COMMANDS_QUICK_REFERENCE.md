# 🎤 Voice Keyboard Commands - Quick Reference

## 🚀 Quick Start

Say any of these commands to AIOS:

### Most Common Commands

```
press enter
press control plus c          # Copy
press control plus v          # Paste
press control plus z          # Undo
type hello world             # Type text
annotate this is important   # Add note
start dictation              # Begin dictating
```

## ⌨️ Keyboard Commands

### Single Keys
```
press [key name]

Examples:
press a
press enter
press escape
press tab
press space
press backspace
press delete
```

### Key Combinations
```
press [modifier] plus [key]

Common shortcuts:
press control plus c          # Copy
press control plus v          # Paste
press control plus x          # Cut
press control plus z          # Undo
press control plus s          # Save
press control plus a          # Select all
press alt plus f4             # Close window
press alt plus tab            # Switch apps
press windows plus r          # Run
```

### Multiple Modifiers
```
press control plus shift plus escape    # Task Manager
press control plus alt plus delete      # Security options
```

### Arrow Keys
```
press up
press down
press left
press right
press home
press end
press page up
press page down
```

### Function Keys
```
press f1 through press f12

Common:
press f5                     # Refresh
press f11                    # Fullscreen
press f12                    # Developer tools
```

### Repetition
```
press [key] [number] times

Examples:
press space 5 times
press enter 3 times
press tab 2 times
```

### Direct Typing
```
type [your text here]

Examples:
type hello world
type user@example.com
type This is a complete sentence
```

### Phonetic Alphabet
```
For clarity, use NATO alphabet:
press alpha              # A
press bravo              # B
press charlie            # C
press delta              # D
press echo               # E
... and so on
```

## 🎙️ Dictation Commands

### Enter Dictation Mode
```
enter dictation mode
start dictation mode
```

### Start Dictating
```
start dictation
```

### Speak Naturally
Just talk naturally, the system will transcribe:
```
This is my first sentence period
New line
This starts a new line period
New paragraph
This starts a new paragraph period
```

```

exclamation point       # !
```

### Line Breaks
```

```

## 💡 Pro Tips

### 1. Use Modifiers Correctly
Always say "plus" between keys:
- ✅ `press control plus c`
- ❌ `press control c`

### 2. Phonetic Alphabet for Clarity
When single letters aren't recognized:
- Instead of: `press a`
- Try: `press alpha`

### 3. Natural Dictation
In dictation mode, speak naturally and add punctuation vocally:
```
[start dictation]
The quick brown fox jumps over the lazy dog period
This is great for long text entry period
[stop dictation]
[insert dictation]
```

### 4. Annotations for Review
Use annotations to mark code or documents for later review:
```
annotate check this logic
annotate potential security issue
annotate optimize this loop
```

### 5. Combine Commands
Switch modes as needed:
```
[in keyboard mode]
enter annotation mode
annotate found a bug here
enter keyboard mode
press control plus f
type search term
```

## 🆘 Troubleshooting

**Command not recognized?**
- Check your pronunciation
- Try the phonetic alphabet for letters
- Ensure you say "plus" between keys
- Check the test suite for exact syntax

**No visual feedback?**
- Verify browser console for errors
- Check that voice input is active
- Ensure page has focus

**Keys not working?**
- Focus an input field for typing commands
- Check that the target accepts keyboard input
- Try the test input field first
